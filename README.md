After the closure of Slightly Mad Studios and the discontinuation of the Project Cars franchise, Project Cars 2 on PC no longer allows you to use the Time Trial feature.

This project uses the game's native external application support along with an export of the time trial database to run a community based time trial service.

Its made up of a Windows client that captures valid laps on any race mode and submits them to the time trial server.

A web interface allows you to browse / filter time trial entries by track, car, class and player name.

The whole implementation is working on my internal testing. I'm working out the details for hosting the web service.

Stay tuned!
